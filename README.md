# Salt & Sugar

**[Live Demo](https://timossom.github.io/Salt-Sugar-Website/)** | **[Releases](https://github.com/Timossom/Salt-Sugar-Website/releases)**

**A responsive restaurant website with an interactive food ordering system.**

Salt & Sugar started as my first HTML/CSS school project and evolved into a JavaScript-powered restaurant ordering demo.

The project demonstrates my progress in front-end web development, from building static pages to implementing interactive features and managing application state.

## Features

### Restaurant Website
- Homepage with food highlights
- Menu with 35 products
- Photo gallery
- Contact page with location map
- Dark design with gold accents
- Responsive layout and mobile navigation

### Interactive Ordering System
- Product customization with ingredient selection
- Optional extras with additional pricing
- Special instructions for individual products
- Quantity selection and automatic price calculation
- Shopping cart with editing and removal options
- Persistent cart using browser localStorage
- Simulated checkout and order confirmation

## Technologies Used

- **HTML5** — Page structure and semantic markup
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript** — Product customization, cart functionality, and user interactions
- **localStorage** — Saving cart data between page refreshes

No frameworks or external JavaScript libraries are required.

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Navigate to the menu.
4. Select products and customize your order.
5. Open the shopping cart and test the demo checkout.


# Salt & Sugar

**A responsive bilingual restaurant website with an interactive food ordering system.**

[Live Demo](https://timossom.github.io/Salt-Sugar-Website/) | [GitHub Releases](https://github.com/Timossom/Salt-Sugar-Website/releases)

## About the Project

Salt & Sugar started as my first HTML/CSS school project and evolved into an interactive restaurant ordering demo using JavaScript.

The project demonstrates my progress in front-end web development, from building static pages to implementing interactive features, managing application state, and adding multilingual support.

The website supports both Greek and English, allowing visitors to browse the menu, customize products, and use the shopping cart in their preferred language.

## Features

### Restaurant Website

- Homepage with food highlights
- Menu with 35 products
- Photo gallery
- Contact page with location map
- Dark theme with gold accents
- Responsive layout and mobile navigation

### Interactive Ordering System

- Product customization with ingredient selection
- Optional extras with additional pricing
- Special instructions for individual products
- Quantity selection and automatic price calculation
- Shopping cart with editing and removal options
- Persistent cart using browser localStorage
- Simulated checkout and order confirmation

### Bilingual Support (GR / EN)

- Switch between Greek and English using the language selector
- Translated navigation, website content, and menu descriptions
- Bilingual product customization, ingredients, and optional extras
- Translated shopping cart and checkout interface
- Language preference saved using browser localStorage
- Switch languages without losing the current shopping cart

## Technologies Used

- **HTML5** — Page structure and semantic markup
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript** — Product customization, shopping cart, and multilingual functionality
- **localStorage** — Saving cart data and language preferences
- **Git & GitHub** — Version control and release management
- **GitHub Pages** — Website hosting and deployment

No frameworks or external JavaScript libraries are required.

## Getting Started

### Live Demo

Visit the website directly:

https://timossom.github.io/Salt-Sugar-Website/

### Run Locally

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Navigate through the website.
4. Switch between Greek and English.
5. Browse the menu and customize products.
6. Add products to the shopping cart.
7. Test the simulated checkout.

To clone the repository:

```bash
git clone https://github.com/Timossom/Salt-Sugar-Website.git
```

## Version History

The initial version focused on learning HTML, CSS, website structure, navigation, and responsive web design.

### v2.0.0 — Interactive Ordering

The second major release introduced JavaScript functionality, including:

- Product customization
- Ingredient selection and optional extras
- Dynamic price calculations
- Shopping cart management
- Persistent cart data using localStorage

This update introduced Greek and English language support throughout the website.

Improvements include:

- Translated menu products and descriptions

- Persistent language preferences
- Improved language switcher styling
